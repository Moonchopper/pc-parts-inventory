## Contracts
```ts
// apps/web/src/lib/money.ts — the D17 rule, one helper for every total on every page:
export function formatTotalOrDash(cents: number, currency: string, coverageCount: number): string;
//   coverageCount === 0 -> '—' ; otherwise formatMoney(cents, currency)   ($0.00 only for a real recorded 0)

// apps/web/src/lib/server/api.ts
export const API_BASE_URL: string;              // env.API_URL ?? 'http://localhost:3000'   (F2)
export const API_TIMEOUT_MS = 5000;             // every SSR request to the API, client + hand-rolled helpers
export class ApiUnreachableError extends Error { readonly url: string }   // timeout / connection refused
export function apiUnreachableMessage(baseUrl: string): string;           // the text the error page shows
```
- `apiUnreachableMessage` must name the URL that was tried, ask whether the API is running, and carry the port
  footgun ("VS Code can squat `127.0.0.1:3000`; run `netstat -ano | findstr :3000`") — the same sentence
  `CLAUDE.md` uses. It renders through the existing `+error.svelte` as a **503**, never a stack trace and never an
  endless spinner.
- **D17**: `Paid` dashes when `coverage.withAcquired === 0`; `Now` dashes when `coverage.withCurrent === 0`; `Δ`
  keeps its existing `comparable.items === 0` guard. Same rule on the share page, the build page and the inventory.
- **F11 progressive enhancement:** the **Download card** link (`<a href="/api/v1/share/{slug}/card.png" download>`)
  is plain HTML and must be present in the **server-rendered** markup. The **Copy card image** button must render
  **only** once JS is running (`$state` + `onMount`, or an equivalent runes-idiomatic guard) and must never appear
  in SSR HTML. Copy path: `fetch` the same-origin card → `blob()` →
  `navigator.clipboard.write([new ClipboardItem({ 'image/png': blob })])`, with a visible success/failure status
  (reuse the Copy-Markdown button's `$state` status pattern); on failure the message points at the Download link.
  Feature-detect `ClipboardItem` — Firefox does not have it, and a `ReferenceError` must not reach the user.
- No change to any API contract, to `@pcpi/contracts`, or to what the pages fetch.
