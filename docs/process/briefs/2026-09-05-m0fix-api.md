3. **F10.** `share/routes.ts:37` is the *only* place a user-facing URL is built in the API:
   `const shareUrl = \`${new URL(c.req.url).origin}/api/v1/share/${shared.slug}\`` — wrong twice (internal origin
   *and* a JSON path). It flows into `renderShareMarkdown(shared, shareUrl)`'s "Generated by" footer.
   `apps/web/src/lib/og.ts` already has a `PUBLIC_ORIGIN` override on the *web* side — same variable name, same
   meaning, different process. `compose.yaml`'s `web` service already sets `ORIGIN: http://localhost:5173`.
4. **F9/D18.** `enqueueJob()` (runner.ts:26) is called from `POST /products/{id}/refresh` (`apps/api/src/products/routes.ts`).
   `startTickLoopUnlessDisabled()` (runner.ts, bottom) is the pattern for env guards: it no-ops under `HARNESS=1`
   and under `process.env.VITEST`. **Your wake must no-op under exactly the same two conditions** — the harness
   drives jobs deterministically through `POST /jobs/run-due` and asserts on how many jobs *that call* ran, so a
   wake that fires under `HARNESS=1` makes `30-pricing` flaky/red. `apps/api/package.json`'s dev script is
   `tsx watch src/serve.ts`, which sets no `NODE_ENV` — that is why `run-due` 404s under `pnpm dev`.
5. **F2.** On Windows a socket on `127.0.0.1:3000` and another on `0.0.0.0:3000` coexist, and the *more specific*
   one wins for `localhost` traffic — that is the whole footgun: our API binds, logs nothing wrong, and every
   request goes to VS Code (or a stale server). The health response has no per-process identity today
   (`{ ok, version, db }`), so the self-check needs one.
6. **The plan's "`60-exports`" is this repo's `tools/harness/checks/50-exports.ts`** (id `exports`) — there is no
   `60-exports.ts`; `60-share.ts` is the share-JSON check. Edit `50-exports.ts`. Checks are discovered by reading
   the directory and run in **filename order**, so a new file's numeric prefix is load-bearing (CLAUDE.md).
7. `packages/contracts/openapi.json` and `packages/contracts/generated/client.d.ts` are **committed build output**
   (`pnpm gen`, after `pnpm build`). Changing the health schema changes both — regenerate and commit them.

**1. F2 — boot self-check.** After `serve()`'s callback prints the port line, call `verifyOwnListener(port)`. On
`ok: false`, log **one loud line** naming the port, what answered instead, and the
`netstat -ano | findstr :{port}` hint, then `process.exit(1)`. On `ok: true`, stay silent.
*Named test* (`apps/api/test/…`): start a stub HTTP listener on `127.0.0.1` that answers
`/api/v1/health` with a *different* `instanceId`, point `verifyOwnListener` at it, assert `ok: false` and that the
reason names the port; plus a positive case against the real app and a timeout case (nothing listening).
Keep the port line first on stdout, unchanged — the harness parses it.

**2. F7/D17 — `—` instead of `$0.00`.** `formatTotalOrDash` in `share/money.ts`; both `markdown.ts` and `card.ts`
use it for Paid and Now. *Named tests*: `withAcquired === 0` → Paid `—`, Now a figure; `withCurrent === 0` → Now
`—`; both zero → both `—` (and the caption's "No prices yet" branch still reads correctly); a **real** recorded
`0` with `withAcquired === 1` still renders `$0.00`. Cover both renderers (`renderShareMarkdown` by string
assertion; the card by asserting on whatever text-extraction seam `card.ts` already gives you — if it has none,
assert on the satori element tree the module builds rather than on PNG pixels).

**3. F9/D18 — wake on enqueue + dev `run-due`.** Debounced single-flight wake in `runner.ts`, guarded exactly like
the tick loop. Dev script sets `NODE_ENV=development`. *Named tests*: three `enqueueJob` calls in one tick run

re-enter; the guard no-ops under `HARNESS=1`. *Live proof* (in the report, with tails): with
`PORT=3020 PRICING_PROVIDERS=fixture DATABASE_URL=file:./data/dev-proof.db pnpm --filter @pcpi/api dev`

`POST /api/v1/jobs/run-due` → **200** (not 404). Kill that server before you report.

**4. F10/D16 — `PUBLIC_ORIGIN`.** Footer becomes `${publicOrigin(requestOrigin)}/b/${slug}`; `compose.yaml`'s `api`
service gets `PUBLIC_ORIGIN: http://localhost:5173`. *Named test*: the rendered Markdown footer contains
`/b/{slug}` and contains **neither** `api:` **nor** `/api/v1/`, with `PUBLIC_ORIGIN` set and unset.
